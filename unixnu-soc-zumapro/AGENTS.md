# Responsibilities

This repository describes the Google Tensor G4 chip, not any particular phone.

A value belongs here only if it is true of the chip. Anything that varies
between phones using it, memory layout, framebuffer address, storage geometry,
panel and peripherals, belongs in the board repository.

Every hardware value must have a named source: the phone's own device tree, a
register read on the device, or vendor documentation. A value copied from a
similar board is not acceptable, and has already cost this project real time.
